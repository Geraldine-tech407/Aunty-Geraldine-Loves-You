Lesson 1: Input Devices

An input device is a hardware component used to enter data and instructions into a computer.

⌨️

Keyboard

Used to enter letters, numbers and symbols.

🖱️

Mouse

Used to point, click, select and move objects.

🎙️

Microphone

Used to input sound or voice into a computer.

📷

Webcam

Captures images and video as input.

Remember: Input means sending data INTO the computer.

Lesson 2: Output Devices

An output device is a hardware component that presents processed information from a computer to the user.

🖥️

Monitor

Displays text, pictures and videos.

🖨️

Printer

Produces printed information on paper.

🔊

Speakers

Produce sound, music and spoken audio.

📽️

Projector

Displays a computer's images on a large screen.

Remember: Output means information coming OUT of the computer.
